# vulkan-manual

Text-only snapshot of the Vulkan sources pinned in gamedev-kb 00_START_HERE.md. Read-only manual source for the gamedev MCP server. Images and binaries are omitted. Updated only when the pin in 00_START_HERE.md changes, by a new snapshot commit that states the new upstream commits.
